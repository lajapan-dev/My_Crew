# 09_テンプレート｜この部屋について

**何をしまう場所か**
毎回ゼロから考えなくていいように、**書式のひな形**を置く引き出しです。

**使い方**
中のファイルをコピーして、使いたい場所に置いて書き込みます。
**AIに「このテンプレで書いて」と頼めば、AIが埋めてくれます。**

| ファイル | いつ使うか |
|---|---|
| `会議メモ.md` | 打ち合わせ・面談のとき |
| `対象記録.md` | 案件・商品・仕入先の記録を1件残すとき |
| `週次レビュー.md` | 週に1回の振り返り |
| `判断記録.md` | 何かを決めたとき |

**増やし方**
同じ形式で3回書いたら、テンプレにする価値があります。AIに作らせてください。
