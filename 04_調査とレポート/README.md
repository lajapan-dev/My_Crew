# 04_調査とレポート｜この部屋について

**何をしまう場所か**
**一度きりの調べもの**の結果をしまう引き出しです。
「あの件、前に調べたはずなんだけど…」を防ぐための場所です。

**ここに入るもの**
- 競合・市場の調査結果
- 新しい商材カテゴリの下調べ
- 助成金・補助金の調べもの
- ツール比較、単発の分析レポート

**ここに入らないもの**
- 継続して面倒を見る対象 → `02_管理対象/`
- 毎月更新する数字 → `03_外部データ/`
- 決めたことと理由 → `05_判断と議事の記録/`

**ファイル名**
`YYYY-MM-DD_調べたこと.md`　例：`2026-10-10_リスキリング助成金の調査.md`

**1枚に書くこと（目安）**
- なぜ調べたか（1行）
- 分かったこと
- で、どうするか（結論・次アクション）

**AIへの指示**
- **「で、どうするか」が空の調査は、価値が半分**。必ず結論を書かせること
- 新しい調査を始める前に、この部屋に**似た調査がないか確認する**
