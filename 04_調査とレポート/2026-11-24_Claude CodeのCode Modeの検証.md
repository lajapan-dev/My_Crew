## なぜ調べたか（1行）

Claude Code（この経営参謀ワークスペースを動かしているAI）に新しく入った「Code Mode」が何者で、自社とお客さまの仕事にどう効くかを確かめるため。

---

## Code Modeとは何か（ひとことで）

**AIが「一手ずつ動く」のをやめて、「段取りを書いた指示書」を作ってまとめて動く方式。**

たとえるなら、お使いの頼み方の違いです。

| | これまで（通常の動き方） | Code Mode |
|---|---|---|
| たとえ | 店に1軒行くたびに電話で報告させ、「次はあの店へ」と毎回指示する | **買い物リストと回る順番を書いたメモ**を渡し、まとめて回ってもらい、**レシートの要点だけ**報告してもらう |
| AIの動き | ファイルを読む → 結果を見る → 次の作業を頼む…を1回ずつ繰り返す | AIが小さなプログラム（JavaScriptという種類の、コンピューター向けの段取りメモ）を書き、それをClaude Codeが一気に実行する |
| 得意なこと | 1つずつ確かめながら進める作業 | **同じ直しを何十ものファイルに入れる**／**検索結果を絞り込んでから読む**／**同時にできる作業を並行して進める** |

公式の説明（要約）：
「Code Modeでは、Claudeが道具（ファイルを読む・直す・命令を実行する等）を呼び出すためのJavaScriptを書き、Claude Codeがそれを実行する。1つの段取りメモで、命令を同時に走らせ、ある結果を次に使い、Claudeが読む必要のある部分だけを持ち帰れる。」

## 提供状況と、使える条件（公式ページより）

**結論：実在する公式機能。ただし「実験中（お試しよりさらに手前）」で、初期設定では切れている。**

| 項目 | 内容 |
|---|---|
| 位置づけ | **実験機能**。公式が「いつでも変更・削除される可能性がある」と明言 |
| 登場時期 | Claude Code の版番号 2.1.323 以降。2026年11月中旬（※公式ページに日付なし。日付は第三者の記事による）[要確認] |
| 使える場所 | **パソコンの「ターミナル」（文字だけで操作する黒い画面）で、対話しながら使うときだけ** |
| **使えない場所** | **クラウド版（ブラウザ・スマホのClaudeアプリから使うClaude Code）**、パソコン用のClaudeアプリ、VS Code（プログラマー向けの編集ソフト）の画面 |
| 必要な契約 | Claudeの有料プラン、または開発者向けの契約。会社の仲介サーバーやAmazon・Google・Microsoftのクラウド経由では使えない |
| オンにする方法 | パソコン側の「Claude Code全体の設定」に、Code Modeを使う印を1つ入れる。**このワークスペースの設定ファイルに書いても無視される**（公式が明記） |
| 一緒に使えない機能 | 遠隔操作（Remote Control）、Chrome操作、パソコン画面の操作 など |
| 会社としての止め方 | 管理者が組織全体で「使わない」に設定できる（逆に、管理者が全員に「使う」を強制することはできない） |

### 安全面で知っておくべきこと（ここが実務家として大事）

- **確認の仕組みは基本的に残る**：段取りメモの中の1つ1つの作業も、これまで通り「これは確認してから」というルールが効く
- **ただし「おまかせモード（auto mode）」では、確認がメモ単位になる**：AIの見張り役は「メモ全体」を実行前に見るだけで、実行中に出てくる具体的な値までは見られない
- **安全な囲い（サンドボックス）の外で動く部分がある**：命令の実行は囲いの中でも、段取りメモそのものと、ファイル・インターネット・外部ツールへのアクセスは囲いの外。公式は「隔離したいなら、専用の仮想パソコンで動かして」と案内
- **一度Code Modeで始めた会話は、Code Modeをオンにしたままでないと再開できない**
- 段取りメモは最大10分で止まる（条件によっては裏で最大2時間）

## 分かったこと（学ぶべき本質）

1. **AIの働き方が「一手ずつ確認しながら」から「段取りを組んでまとめて実行」へ進んでいる**
   - 人間の仕事でいえば、新人が毎回「次どうしますか？」と聞く段階から、**段取りを自分で組んで、結果だけ報告する中堅**になる流れ
   - 読む量（AIの頭の中の机の広さ）を節約できるので、大量のファイルやデータを扱うほど効く
2. **ただし、任せる範囲が広がるほど「止めどころ」を人が決める必要がある**
   - 「おまかせ」と組み合わせると、確認の粒度が粗くなる。送信・削除・お金に関わる操作は、これまで以上に「必ず人に確認」のルールを明確にしておくべき
   - これは `CLAUDE.md` の「AIが提案までに留める領域」の考え方がそのまま効く
3. **今は「プログラマー寄りの、パソコンで使う人向けの実験機能」**
   - クラウド版・スマホ・パソコン用アプリでは使えない。経営者がふだん触る画面では、まだ使えない

## で、どうするか（結論・次アクション）

### 自社の仕事への効き方（判断基準との対応）

| 使い道 | 判断 | ラベル |
|---|---|---|
| **このワークスペースの日々の運用**（朝ブリーフ・雑メモ整理・todo） | 本間さんはクラウド版（ブラウザ・スマホ）で使っているため、**今は使えない**。また、このワークスペースは文章中心でファイル数も約80と少なく、Code Modeの効き目はもともと小さい | 【低】 |
| **将来、大量データを扱うとき**（例：SKU約2,000件の一覧から粗利の要約を作る、全研修資料の表記を一括で直す） | ここで初めて効く。パソコンのターミナルでClaude Codeを使う体制になってから | 【低】【仕組み化候補】→ 次の段階の候補リストへ |
| **AI研修のネタ** | 「AIが一手ずつではなく段取りを組んで動く時代」「任せるほど止めどころのルールが要る」は、経営者・管理職に伝わる話。**機能そのものより"任せ方のルール"を語れるのが差別化** | 【中】【コンテンツ資産化】 |
| **AIパッケージ（お客さま向け）** | 実験機能で、ターミナルでしか動かないため、**標準に入れるのは早い**とAIは判断。「ターミナルで使えるお客さま向けの上級設定」として控えに置く案 | 【要本人判断】 |

### 今はやらないこと

- **このワークスペースでCode Modeをオンにする**：クラウド版では動かず、設定もこのワークスペースからは入れられない仕組み。【低】
- **SNSでの紹介投稿**：【捨てる】自社SNS発信は今期DON'Tリストに該当（`01_会社の土台/06_DONTリスト.md`）
- **お客さまに標準で入れること**：実験機能のため、提供元の都合で消える可能性がある。【低】
