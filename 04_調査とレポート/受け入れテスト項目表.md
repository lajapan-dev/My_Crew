## 0. はじめに（必ず読んでください）

### 0-1. この表の目的
オンライン版で導入したパソコンと、USB 版で正しく導入したパソコンが **同じ状態・同じ動き** になるかを確かめます。
パッケージの中身を知らない人でも実行できるように、確かめる手順と、合否を決める具体的な結果を書いています。

### 0-2. どの版を根拠にしたか（重要）
- 今回読んだのは、本間さんの Google ドライブにある **「ClaudeCode設定パッケージ」フォルダ** です（2026-11-17 にドライブへアップロードされたもの）。
- そのフォルダの表示は次のとおりです。
  - README の表記は「**2026-10-22版**」
  - 中のファイルの更新日は **2026-11-12**
  - 同梱一覧（manifest.tsv）の生成日時は **2026-11-12 18:42**
- **「v12」と同じ中身かどうかは、こちらでは確かめられていません。**
  ドライブには別に `ClaudeCodeSetupPackage_v12_20261007.zip`（10月7日）がありますが、ここからは開けませんでした。
  **開発側が使っている正本と日付が違う場合は、先に版をそろえてください。** 版がずれていると、正しい動きを「不合格」と判定してしまいます。
- パッケージのファイルは一切変更していません。
- **2026-11-23 追記**：表を作ったあと、設計側で決められることを決めました。内容は「9. 設計側で決めたこと」にまとめ、関係する項目も直してあります。

### 0-3. 表の読み方
- **WS** ＝ 仕事フォルダ（既定は Mac `~/ClaudeWorkspace`、Windows `%USERPROFILE%\ClaudeWorkspace`）
- **PKG** ＝ パッケージのフォルダ（オンライン版ではホームの `ClaudeCode設定パッケージ`）
- **~** ＝ ホームフォルダ（Windows では `%USERPROFILE%`、PowerShell では `$HOME`）
- **OS 欄**：両方／Mac／Win
- **優先度**：必須（不合格なら出荷しない）／重要（直してから出したい）／できれば
- **★** が付いた項目は、過去に不具合があった所、または設計上とくに壊れやすい所です。優先度を上げています。
- **設問欄**：ヒアリングの回答で結果が変わる項目には、関わる設問の番号（Q1〜Q88）を書いています。
- 「Claude に送る文」は、**仕事フォルダ（WS）を Claude デスクトップアプリの Code タブで開いた状態** で送ってください（PKG で送るものはそう書いています）。
- 根拠のパスは、すべて **PKG からの位置** です。

1. まっさらなテスト用パソコン（Mac 1台・Windows 1台。Windows は **ユーザー名が英数字のもの** と **日本語のもの** を1台ずつ用意できると理想です。「7. 懸念」の K-05）
