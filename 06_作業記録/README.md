# 06_作業記録｜この部屋について

**何をしまう場所か**
**その日やったこと**を短く残す引き出しです。日報のようなものですが、
提出先は誰もいません。**あとで自分とAIが振り返るためだけ**のものです。

**なぜ必要か**
本間様は1日のうちに「提案・登壇・コンサル・Shopee実務」を行き来しています。
頭の切り替えが多いと、**やったこと自体を忘れます**。
週次の振り返りや、時間配分の提案は、この記録があると精度が上がります。

**書き方**
- **完璧に書かなくてよい。3行でよい**
- テンプレは `_フォーマット.md`。面倒なら箇条書きだけでもよい

**ファイル名**
`YYYY-MM-DD.md`（1日1ファイル）

**更新頻度**
毎日が理想。**ただし最初の1か月は、書ける日だけでよい**。
続かないくらいなら、週1回まとめてでも構いません。

**AIへの指示**
- 週次レビューのとき、この部屋の直近1週間を読む
- 記録から **時間の使い方の偏り**（営業／コンテンツ／コンサル実務）を指摘する
- 繰り返し出てくる作業には **【仕組み化候補】** を付ける
