# 12_AI組織ダッシュボード｜AIの社員たちが働く様子を「見える化」する画面

最終更新：2026-10-31

## この部屋は何か

AIの社員たちが組織図の上で仕事を受け渡しする様子を、**ライブ中継のように見せる画面** の置き場所です。
本間さんが「AIパッケージで採用したい」と決めたもの（2026-10-31）。Threadsで見かけた投稿を参考にしています。

- **中身**：`AI組織ダッシュボード.html`（ダブルクリックするとブラウザで開く1枚の画面）
- **今の状態**：**デモ（見本）**。数字も動きも見本で、実際の仕事の記録とはまだつないでいない

## 画面の読み方

| 場所 | 何を表しているか |
|---|---|
| いちばん上の帯 | 時計・稼働日数・今日の出動回数・AIで片付けた件数・**本人に回した件数**・24時間の出動グラフ |
| 数字の帯 | 今期の目標に対する進み具合（AI月商・新規問い合わせ・Shopee粗利率・返信テンプレ・右腕AIの自動回答率） |
| 本間 洋平（金色） | 社長・最終決定。AIが「要本人判断」と判断したものだけが、ここに赤いバッジ付きで届く |
| 経営参謀（青） | Claude Code。仕事を受けて、5つの部署（朝ブリーフ／AI研修／Shopee／仕組み化／品質・ガード）の係に振り分ける |
| 右腕AI（緑） | LINE公式アカウント。社員からの質問に即答し、お金・クレーム・契約だけを本間さんに回す |
| 会社の記憶（星座） | このワークスペースの部屋。AIが仕事のたびに **憲法（CLAUDE.md）→ 全体像（SUMMARY.md）→ 必要な部屋だけ** の順に読む様子が光る |
| いちばん下の帯 | 「誰が誰に何を頼んだか」の記録が流れる |

**係の名前・仕事の流れは、このワークスペースの実際のルールに合わせてあります。**
たとえば「DON'Tチェック係」が「Lazadaにも出す？」を「今期はやらない【捨てる】」と止める、返金の相談は判定係が本間さんに回す、など。

## AIパッケージでの使い方（案）

1. **営業・登壇の場で見せる**
   「AIを入れると、社長の机に届くのは"判断が必要なものだけ"になる」を、一目で伝える見本として使う。
2. **お客さまごとに作り替える**
   画面の中身は、ファイルの上のほうにある「設定」の部分だけで決まっています。
   Claude Codeに次の項目を伝えて「この会社用に作り替えて」と頼めば、お客さま版ができます。

**お客さま版を作るときにAIに伝えること（チェックリスト）**
- [ ] 会社名・代表のお名前（画面に出してよいか、記号にするか）
- [ ] 部署と、それぞれの係の名前・仕事内容（3〜5部署が見やすい）
- [ ] 社員の質問窓口（LINE等）を入れるか
- [ ] 上に並べる目標の数字（3〜5個）
- [ ] 「社長に回すもの」の基準（お金・クレーム・契約 など）
- [ ] 仕事の流れの見本（その会社でよくある依頼を5〜10個）

> **価格・パッケージ内容への入れ方は、本間さんが決める領域です。** AIは案を出すところまで。

## 注意（必ず守ること）

- **見た目・キャラクター・名前は、参考にした投稿をまねていません**（オリジナルで作成）。売り物に使うので、今後も他人の画面やキャラクターをそのまま写さないこと
- お客さまに見せるときは、**「デモ表示：数字と動きは見本です」の表示を消さない**（実データとつなぐまでは）
- 実データをつないだ版では、**クライアント名・金額・個人情報を画面に出さない**（「A社」等の記号にする）
