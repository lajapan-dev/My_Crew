# 08_todo｜この部屋について

**何をしまう場所か**
やることリストです。ただし**ただの一覧ではありません**。
AIが優先順位をつけられるように、「なぜやるのか」「放っておくとどうなるか」まで書ける形にしています。

**3つに分けている理由**
| ファイル | 中身 | なぜ分けるか |
|---|---|---|
| `todo_AI研修.md` | 事業Aのやること | 事業ごとに頭を切り替えるため |
| `todo_Shopee.md` | 事業Bのやること | 同上 |
| `todo_仕組み化.md` | 緊急でないが重要なこと | **これが埋もれるのを防ぐため（最重要）** |

**`todo_仕組み化.md` を分けている理由**
仕組み化は「急がないが、やらないと永遠に自分が止まると全部止まる」種類の仕事です。
日々のタスクと同じ場所に置くと、**必ず後回しになって消えます**。だから別にしています。

**書き方**
- **全部の欄を埋めなくてよい**。タスク名だけでも書いてください
- 埋まっているほど、AIの優先順位づけの精度が上がります

**AIへの指示**
- 優先順位は `01_会社の土台/04_判断基準.md` の序列に従って、**毎回つけ直す**
- 書かれた順番は優先順位ではない。**AIが並べ替えるのが前提**
- `todo_仕組み化.md` からは、**毎週必ず1つ進捗を提案する**
- DON'Tリスト該当のものには **【捨てる】** を付けて、はっきり打ち切る
