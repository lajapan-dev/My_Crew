# /setup — 導入先企業の初期設定ヒアリング

導入先企業の意向を一問一答で聞き取り、`.claude/company/company-config.md` を自動生成し、業務に必要なエージェントをライブラリから有効化する。

## 進め方の原則

- **必ず1問ずつ**質問する。複数の質問を同時にしない。
- 各質問には選択肢(A/B/C…)を付け、自由回答も受け付ける。
- 回答が曖昧なときは1回だけ確認し、それでも曖昧なら妥当な解釈を選んで進める(後から編集できることを伝える)。
- 全問終わったら**ヒアリング結果の全体まとめを表形式で提示し、OK をもらってから**ファイルを生成する。

## 質問リスト(この順で1問ずつ)

1. **企業名・事業内容** — 御社名と事業内容を一言で教えてください。
2. **導入目的** — Claude Code を主にどんな業務に使いたいですか?(例: 動画・画像制作 / 資料作成 / 文書作成 / 開発 / その他)
3. **主なユースケース詳細** — 質問2で挙がった業務について、具体的な作業内容・頻度・成果物のイメージを教えてください。
4. **応答の口調** — Claude の応答はどの口調がよいですか?(A: 丁寧なビジネス敬語 / B: 標準の敬体(です・ます) / C: フランク / D: その他)
5. **報告形式** — 作業報告はどの形式がよいですか?(A: 結論のみ簡潔に / B: 結論+要点の箇条書き / C: 詳細まで報告)
6. **社内用語・NGワード** — 応答で使ってほしい社内用語や、避けてほしい表現はありますか?(なければ「なし」)
7. **追加エージェント** — 標準搭載(動画・画像生成、スライド作成)以外に必要な専門機能はありますか?(例: コードレビュー、SEO記事、データ分析、翻訳など。なければ「なし」)

## ヒアリング後の処理(OK をもらってから自動実行)

1. `.claude/company/company-config.md` を回答内容で上書きする。見出し構成は現在のテンプレート(企業情報 / 業務内容・ユースケース / 応答の口調・スタイル / 有効化した追加エージェント)を維持する。
2. 質問7で追加機能の要望があった場合:
   - `.claude/agents-library/` 配下(wshobson-agents / voltagent-subagents / 0xfurai-subagents / davepoon-collection)を Grep で検索し、要望に合うエージェント定義を探す。
   - 候補を最大3件提示し、ユーザーが選んだものだけを `.claude/agents/` にコピーして有効化する。
   - 有効化したエージェント名と出典を company-config.md の「有効化した追加エージェント」に記録する。
   - **一度に有効化するのは5体まで**。それ以上はコンテキストを圧迫し応答品質が落ちることを伝え、絞ってもらう。
3. 生成した company-config.md の内容を表示して完了報告する。設定変更はいつでも `/setup` の再実行かファイル直接編集でできることを伝える。

## 禁止事項

- `.claude/base/common-rules.md` は編集しない(全導入先共通の実績あるルールのため)。
- ヒアリングを飛ばして推測で設定ファイルを書かない。
- ライブラリのエージェントを一括で大量有効化しない。
