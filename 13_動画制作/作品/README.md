# 作品フォルダ｜1本ごとの記録を溜める場所

**この箱に何を入れるか**
動画1本につき1つのフォルダを作り、次のファイルを入れます。

| ファイル | 中身 | 誰が書くか |
|---|---|---|
| `絵コンテ.md` | 企画・カット表・Omni投入シート・振り返り | 絵コンテ監督（AI） |
| `生成ログ.md` | いつ・どのブロックを・何案作ったか、採用した案、失敗の理由、使ったクレジット | AI（本間さんは一言メモでよい） |

**動画ファイルそのもの（重いファイル）はここに入れません。** Googleドライブなど元の場所に置き、ここには置き場所だけ書きます。

**フォルダ名の付け方**
`YYYY-MM-DD_作品名`　例：`2026-12-01_Shopee商品ページ_A商品`

**更新の頻度**
動画を1本作るたび。完成後に「振り返り」を1〜3行書く。

**入れ方のコツ**
- 失敗した生成こそ記録する（「手元を寄りで撮ると指が崩れた」など）。次の絵コンテが良くなります
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたとき・似た動画を作るときだけ読むこと。
