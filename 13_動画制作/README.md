# 13_動画制作｜絵コンテを作り、Omniで動画にする部屋

最終更新：2026-11-23

## この部屋は何か
**AIで作る動画の「設計図（絵コンテ）」と、その記録をしまう部屋** です。
動画づくりは「いきなりAIに作らせる」と素人っぽくなります。
プロの映像会社と同じく、**先に絵コンテで1カットずつ決めてから作る** ことで、仕上がりが段違いになります。

## 流れ（5段階）

| 段階 | 誰がやるか | 何をするか | 本間さんの手間 |
|---|---|---|---|
| ① 依頼 | 本間さん | 「何のため・誰に・見た後どうしてほしいか・長さ」を伝える（雑でよい） | 1〜2分 |
| ② 絵コンテ | 絵コンテ監督（AI） | 企画の芯 → 構成 → 見た目の決まりごと → カット表 → Omni投入シート まで作る | なし |
| ③ 確認 | 本間さん | ★印の欄と「費用の見積もり」だけ見て、OKか直しを出す | 5分 |
| ④ 生成 | 本間さん（Klingの画面で） | Omni投入シートを1ブロックずつ貼って生成。2案ずつ作って良い方を選ぶ | 1ブロック数分 |
| ⑤ 仕上げ | 本間さん or 外注 | 動画をつなぎ、文字・ナレーション・BGM・ロゴを編集ソフトで入れる | 15〜30分 |

**なぜ文字やロゴを最後に入れるのか**：AIは画面に文字を描くのが苦手で、崩れた文字が出ると一気に安っぽくなるためです。

## 絵コンテ監督（AI）への頼み方
雑な一言で構いません。例：
- 「AIリスキリング研修の紹介動画を、絵コンテ監督で作って。説明会の冒頭で流す30秒、横長」
- 「Shopeeの商品ページに載せる15秒の動画の絵コンテ。商品写真はこれ」

足りない情報があれば、AIが質問を返します。
**AIが勝手に生成（お金のかかる操作）をすることはありません。** 見積もりを見て「生成してよい」と言ったときだけ動きます。

## 中に入っているもの

| 名前 | 何か |
|---|---|
| `作品/` | 1本ごとのフォルダ。絵コンテ・生成の記録・振り返りを溜める |
| `作品/2026-11-23_見本_AIリスキリング研修紹介/` | **見本の絵コンテ①**（30秒・横長・2ブロック・人物あり）。最初の1本はこれを生成して慣れるのがおすすめ |
| `作品/2026-11-23_見本_Shopee商品動画_マグカップ/` | **見本の絵コンテ②**（15秒・縦長・1ブロック・商品だけ）。商品を差し替えれば使い回せるShopee商品ページ用の型 |
| ひな形 | `09_テンプレート/絵コンテ.md` |
| AIの手順書 | `.claude/agents/ekonte-kantoku.md`（絵コンテ監督の中身。ふだん開く必要はありません） |

## 今のつながり方（大事）
- **Omni での本番生成は、Klingの画面で本間さんが貼り付けて行います。** 今このワークスペースにつながっているKlingの道具は、Omniの手前の版（v2）までしか動かせないためです
- AIが道具で直接やれるのは、**人物や商品の参照用の静止画づくり** と **1カットだけの試し撮り** です
- KlingのOmniを直接動かせる道具が出たら、④の生成もAIに任せられます →「将来の候補」

## どんな動画を優先するか（判断基準に沿って）
- **優先して作る**：研修教材・説明会や提案書で使う紹介動画・Shopee商品ページ用動画 【コンテンツ資産化】
- **今期は作らない**：自社SNSでの宣伝用（DONTリスト「自社SNS発信」に当たるため）
- **ずっと作らない**：他社のキャラクター・アニメ・ブランドロゴ・実在の他人の顔や声を使うもの（正規IPルートの恒久ルール）
