# 事業の成り立ち｜2つの事業はどうつながっているか

最終更新：2026-09-15

AIが「なぜこの2つを同時にやっているのか」を理解するためのファイルです。
これが分かっていないと、AIは2事業をバラバラの会社のように扱ってしまいます。

---

## 1. 全体像を一言でいうと

> **「自分が実際にやって成果が出たことを、教えて売る」**

これが2つの事業に共通する型です。

- 自社でShopeeを実際に回す → その知見をコンサル・研修として売る（事業B）
- 生成AIを実務と大学教育の両方で扱う → その知見を法人研修として売る（事業A）

つまり **「実務 → 知見 → 教材・研修 → 売上」** という一本の流れがあり、
2事業はその流れを別テーマで走らせているものです。

---

## 2. 生まれた順番

**① 事業開発のキャリア（2000年〜）**
ロサンゼルスでのポータルサイト立ち上げに始まり、コンサル、上場企業のビジネスモデル構築へ。
ここで「事業をゼロから形にする」経験が蓄積される。

**② 越境EC（Shopee）への集中**
実務として自らShopeeを運営。売れる商品の見つけ方、国別の違い、手数料・送料の構造、
アカウントを守る運用を、身体で覚える。
その実績が認められ、**Shopeeオフィシャルパートナー**に。
→ ここから **事業B（Shopeeコンサル）** が立ち上がる。

**③ 生成AIの専門性**
生成AIを実務に取り込むうちに専門性が高まり、**東北大学で教えるレベル**に到達。
大学で教えている内容を法人向けに翻訳したものが「東北大学カリキュラム」。
→ ここから **事業A（AI研修）** が立ち上がる。

---

## 3. 2つの事業の関係

**共通しているもの**
- 売っているのは「代表本人の実務知見」
- 売り方も同じ（代表が営業し、代表が登壇する）
- だからこそ、**両方とも代表の時間がボトルネックになる**

**違っているもの**

| | 事業A：AI研修 | 事業B：Shopeeコンサル |
|---|---|---|
| 顧客 | 主に法人 | 越境EC事業者 |
| 単価の作り方 | 研修プログラム（40万円規模のバックエンド） | コンサル契約（スポット／継続） |
| 伸ばし方 | **案件の頻度**を増やす（助成金活用） | **粗利率**を上げる |
| 今の位置づけ | 伸ばす | 構造を改善する |

**互いに効いていること**
- AI研修で得たAI活用ノウハウは、Shopee運営の効率化に使える
- Shopee実務は、AI研修で語れる「実例」になる
- 自社Shopeeアカウントは、事業Bの事例・データ源であり、同時に事業Aの教材ネタでもある

---

## 4. 今、構造として抱えている問題

1. **どちらの事業も、代表の時間を同じ場所から引き出している**
   （営業・登壇・実務。だから片方が忙しいと、もう片方が止まる）
2. **頭の切り替えコストが高い**
   （提案・登壇・コンサル・Shopee実務を1日のうちに行き来する）
3. **蓄積が残っていない**
   （やったことが記録されず、次に再利用できない）

→ このワークスペースは、**3の「蓄積が残らない」を先に解く**ことで、
1と2を段階的に軽くしていくための土台です。

---

## 5. だからAIはこう振る舞うこと

- 提案するときは、**どちらの事業の話かを必ず明示する**（事業A／事業B）
- 「代表の時間を使う提案」には、**振り先（AI・テンプレ・外注）をセットで書く**
- 実務で出てきた知見は、**【コンテンツ資産化】** のラベルを付けて、教材・書籍への転用を促す
