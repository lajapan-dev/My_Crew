# 01_会社の土台｜この部屋について

**何をしまう場所か**
会社と代表についての、**あまり変わらない前提情報**をしまう引き出しです。
日々動くもの（案件・数字・todo）はここには置きません。

**なぜここに置くのか**
AIが経営判断を手伝うには、「この会社は何者で、何を大事にしていて、何をやらないのか」を
先に知っている必要があります。ここが空だと、AIは一般論しか返せません。

**中身**
| ファイル | 中身 |
|---|---|
| `01_会社概要.md` | 会社の基本情報・事業一覧・体制 |
| `02_代表プロフィール.md` | 本間代表の経歴・価値観・得意分野 |
| `03_事業の成り立ち.md` | 2つの事業がどう生まれ、どうつながっているか |
| `04_判断基準.md` | 優先順位づけの絶対ルール（AIが毎回従う） |
| `05_優先度マトリクス.md` | 高・中・低の具体例 |
| `06_DONTリスト.md` | 今期やらないと決めたこと |
| `07_社内用語集.md` | 社内の言葉・略語の意味 |
| `08_次の段階の候補リスト.md` | 慣れてから取り組むとよいこと |

**更新の目安**
半年に1回、または方針が変わったとき。`[要確認]` と書かれた箇所は、
分かり次第うめてください。**推測では埋めません。**
