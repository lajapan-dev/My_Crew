# 導入の道のり｜右腕AIを動かすまでの手順と、決めておくこと

最終更新：2026-10-27

---

## 1. まず大事なこと：個人のLINEは自動化しない

いま社員からの質問は、本間さんの **個人のLINE** に届いています。
ここにAIをつなぐことは **しません。** 理由は3つです。

- **LINEの規約で禁止されている**：個人のLINEを機械に自動で操作させる方法は、LINEが認めていません。見つかると **アカウントが止められる** おそれがあります
- **止まったときの被害が大きい**：個人のLINEが止まると、家族・友人・取引先とのやり取りも全部失います
- **AIに読ませたくない会話まで読まれる**：個人のLINEには、仕事以外の会話も入っています

そこで、**社員専用の「LINE公式アカウント」を新しく1つ作り**、社員には「仕事の質問はこちらへ」と切り替えてもらいます。
LINE公式アカウントは、お店や会社が作る **緑の盾マークのアカウント** で、LINEが正式にAIとのつなぎ込みを認めています。

> たとえるなら、**自宅の電話（個人LINE）に留守番ロボットを付けるのではなく、会社の代表電話（公式アカウント）を1本引いて、そこに優秀な受付係（右腕AI）を座らせる** イメージです。

---

## 2. できあがったときの姿

1. 社員が、公式アカウント「右腕AI」に質問を送る
2. 右腕AIが、**本間さんの判断基準（応答ルール）を読んで、数秒で返信する**
3. 本間さんの判断が必要なものだけ、本間さんに届く
   - **緊急**（Shopeeの違反警告など）→ すぐメールで届く（希望すればLINEにも）
   - **今日中**（AI研修の新規問い合わせなど）→ 昼間はすぐ、夜間・休日は翌朝
   - **それ以外** → **毎朝のまとめメールに1本にまとまって届く**
4. すべてのやり取りは、Googleスプレッドシートの「応答ログ」に自動で残る

**本間さんの毎日の仕事は、朝のまとめメールを1通読むことだけ** になるのが目標です。

### 社員以外が使えないようにする工夫
公式アカウントは、誰でも友だち追加できてしまいます。
そこで、**社内だけで共有する「合言葉」を最初に送った人だけ** が使えるようにしてあります。
合言葉を知らない人には、AIは何も答えません（会社の判断基準が外に漏れないように）。

## 3. 準備するもの

| 準備するもの | 何のためか | 費用の目安 |
|---|---|---|
| **LINE公式アカウント**（新しく作る） | 社員が質問を送る窓口 | 無料プランで始められる。AIからの「返信」は無料の範囲で使える（※最新の料金はLINE公式サイトで確認） |
| **Claudeの利用契約（API）** | AIの頭脳。使った分だけ支払う | 1回の質問あたり数円〜十数円。1日30問なら **月5,000〜1万円程度** の目安。**月の上限金額を設定できる** ので、使いすぎの心配はない |
| **Googleアカウント**（今お使いのもの） | 応答ルールの置き場所、記録表、仕組みを動かす場所 | 無料 |

## 4. 進め方（4段階）

### ステップ1｜本間さんが「任せてよい範囲」を書く（30分）
`03_よくある質問.md` の **「A. 本間さんが決めた『社員に任せてよい範囲』」** の表に答えを書き込みます。
- 例：「在庫が7日分を切ったら発注」「返金は3,000円までは社員判断でよい」
- **全部埋めなくて大丈夫です。** 空欄の項目は、AIが本間さんに回します
- 書き込むほど、本間さんに回ってくる件数が減ります

### ステップ2｜仕組みを設置する（半日）
`仕組み/設置手順.md` に、画面のどこを押すかまで書いてあります。
- ITに詳しい方なら半日で終わる分量です。外部の方に頼む場合は、このフォルダごと渡してください
- 本間さんに作業していただくのは、**LINE公式アカウントの作成** と **Claudeの支払い設定** だけです（どちらも本人名義が必要なため）

### ステップ3｜試運転（2週間・社員1〜2名で）
- まず1〜2名にだけ使ってもらいます
- 本間さんは毎朝のまとめメールを見て、**「この答えは違う」と思ったら、その質問と正しい答えを雑メモに1行書く** だけでOK
  → Claude Code（経営参謀）が、応答ルールの直し方を提案します
- 応答ルールのGoogleドキュメントを直すと、**10分以内に右腕AIの答え方が変わります**

### ステップ4｜全社員に広げる
- 試運転で大きな問題がなければ、全社員に案内します（下の文例を使えます）
- 以後、**仕事の質問は個人LINEではなく右腕AIへ** を社内ルールにします

## 5. 社員へのお知らせ文例（コピーして使えます）

> みなさんへ
>
> 仕事の質問の窓口として、LINE公式アカウント「右腕AI」を作りました。
> これからは、仕事の質問は私の個人LINEではなく、こちらに送ってください。
>
> 右腕AIは、私の判断基準（優先順位の付け方、やらないと決めていること等）を覚えたAIです。
> 24時間、すぐに答えます。私の判断が必要なものは、右腕AIから私に伝わり、私から返事をします。
>
> 【使い方】
> 1. 下のQRコードから友だち追加
> 2. 最初に合言葉「（ここに合言葉）」を送る
> 3. あとは普通に質問を送るだけ
>
> AIの答えがおかしいと感じたら、遠慮なく私に教えてください。答え方を直していきます。
>
> 本間

## 6. 慣れてから取り組むとよいこと（将来の候補リスト）

今回は「社員の質問に、文字で、1対1で答える」ところまでに絞っています。
次の項目は **やらないのではなく、順番を後ろにしたもの** です。慣れてきたら、いつでも相談してください。

| 候補 | なぜ今ではないか |
|---|---|
| **コンサル先・お客様からの問い合わせにも自動で答える** | 社外の方への返答は、間違えたときの影響が大きい。まず社員向けで答えの精度を上げてから |
| **在庫表・売上表を読んで、数字でも答える** | 今はSKU別の粗利一覧づくりの途中。元データが整ってからつなぐ方が、正しい答えになる |
| **写真・スクリーンショットを読んで答える** | 技術的にはできるが、費用が上がる。まず文字でどれくらい質問が来るか見てから |
| **社員のグループトークに参加させる** | 誰に向けた質問かの判断が難しくなる。1対1で慣れてから |
| **Chatworkにも同じ右腕AIを置く** | 窓口を増やすと、記録が分かれる。まずLINE1本に集約してから |
| **よくある質問の自動追加** | AIが勝手に手本を増やすと、本間さんの意図とずれる。最初は人が確認して足す方が安全 |
