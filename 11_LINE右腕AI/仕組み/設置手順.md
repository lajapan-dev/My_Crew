# 設置手順｜右腕AI（LINE × Claude × Googleスプレッドシート）

最終更新：2026-10-27

この手順書は、**設置を担当する方**（本間さん本人、またはITに詳しい協力者）向けです。
プログラムを書く作業はありません。画面のボタンを押す・文字を貼り付ける作業だけで終わります。目安は半日です。
※ LINEやGoogleの画面の名前は、時期によって少し変わることがあります。

---

## 全体の部品

| 部品 | 役目 | 置き場所 |
|---|---|---|
| LINE公式アカウント | 社員が質問を送る窓口 | LINE |
| 応答ルール（Googleドキュメント） | AIが毎回読む「答え方の憲法」 | 本間さんのGoogleドライブ |
| 応答ログ（Googleスプレッドシート） | やり取りの記録と、社員名簿 | 本間さんのGoogleドライブ |
| コード.gs | 上の3つとClaudeをつなぐ小さなプログラム | スプレッドシートの「Apps Script」 |
| Claude（API） | AIの頭脳 | Anthropic社 |

---

## 手順1｜LINE公式アカウントを作る（本間さん名義で）

1. 「LINE公式アカウント」の管理画面（LINE Official Account Manager）で、新しいアカウントを作る
   - アカウント名の例：「右腕AI（本間）」
2. 管理画面の **設定 → Messaging API** で「Messaging APIを利用する」を押す
3. 管理画面の **応答設定** で、次のようにする
   - **応答メッセージ：オフ**（LINEの定型自動返信と二重にならないように）
   - **Webhook：オン**
4. 「LINE Developers」の画面を開き、このアカウントのチャネルの **Messaging API設定** で
   **チャネルアクセストークン（長期）** を発行して、控えておく（あとで ①LINE_CHANNEL_ACCESS_TOKEN に使う）

## 手順2｜Claudeの利用契約をする（本間さん名義で）

1. Claudeの開発者向け画面（Claude Console）にログインし、支払い方法を登録する
2. **月の利用上限額を設定する**（最初は月1万円程度がおすすめ）
3. **APIキー** を新しく作り、控えておく（あとで ②ANTHROPIC_API_KEY に使う）
   - APIキーは「合鍵」です。人に見せたり、メールやチャットに貼ったりしないでください

## 手順3｜応答ルールのGoogleドキュメントを作る

1. Googleドライブで新しいドキュメントを作る（名前の例：「右腕AI_応答ルール」）
2. 次の2つの中身を、続けて貼り付ける
   - `02_応答ルール.md` の「ここから下をGoogleドキュメントに貼る」より下
   - `03_よくある質問.md` の「ここから下をGoogleドキュメントに貼る」より下
3. ドキュメントのアドレス（URL）の `/d/` と `/edit` の間の長い英数字を控える（③RULES_DOC_ID）

## 手順4｜応答ログのGoogleスプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作る（名前の例：「右腕AI_応答ログ」）
2. アドレスの `/d/` と `/edit` の間の長い英数字を控える（④LOG_SHEET_ID）
   - 「応答ログ」「社員名簿」のシートは、あとで自動で作られます

## 手順5｜仕組み（コード.gs）を入れる

1. 手順4のスプレッドシートで、上のメニュー **拡張機能 → Apps Script** を開く
2. 最初からある文字をすべて消し、`コード.gs` の中身をすべて貼り付けて保存する
3. 左の歯車（**プロジェクトの設定**）で
   - **タイムゾーン** を「(GMT+09:00) 東京」にする
   - 下のほうの **スクリプト プロパティ** に、次の6つ（＋任意で1つ）を登録する

| プロパティ名 | 入れる値 |
|---|---|
| ① `LINE_CHANNEL_ACCESS_TOKEN` | 手順1-4のチャネルアクセストークン |
| ② `ANTHROPIC_API_KEY` | 手順2-3のAPIキー |
| ③ `RULES_DOC_ID` | 手順3-3の英数字 |
| ④ `LOG_SHEET_ID` | 手順4-2の英数字 |
| ⑤ `OWNER_EMAIL` | 本間さんがまとめメールを受け取るアドレス |
| ⑥ `PASSPHRASE` | 社員だけに教える合言葉（例：好きな言葉＋数字。推測されにくいもの） |
| ⑦ `OWNER_LINE_USER_ID`（任意） | 緊急時に本間さんのLINEにも知らせたい場合だけ。手順9で調べる |

4. 画面上部で関数 **setup** を選んで「実行」を押す
   - 初回は「権限を確認」と出るので、本間さんのGoogleアカウントで許可する
   - 「このアプリはGoogleで確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進めてよい（自分で作った仕組みのため）
   - 下の実行ログに「設定OK」と出れば成功
5. 関数 **testAnswer** を選んで「実行」を押す
   - 実行ログに、AIの答え（在庫の質問への回答）が表示されれば、Claudeとのつながりは成功

## 手順6｜インターネットに公開して、LINEとつなぐ

1. Apps Script 右上の **デプロイ → 新しいデプロイ**
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
2. 「デプロイ」を押し、表示された **ウェブアプリのURL** をコピーする
3. LINE Developers の **Messaging API設定** で
   - **Webhook URL** に、いまのURLを貼って「更新」→「検証」
   - **Webhookの利用：オン**

## 手順7｜毎朝のまとめメールを設定する

1. Apps Script 左の時計マーク（**トリガー**）→ 右下「トリガーを追加」
2. 次のように設定して保存
   - 実行する関数：**sendMorningDigest**
   - イベントのソース：**時間主導型**
   - 時間ベースのトリガーのタイプ：**日付ベースのタイマー**
   - 時刻：**午前7時〜8時**

## 手順8｜動作確認

1. 自分のスマホで公式アカウントを友だち追加する
2. 適当な言葉を送る → 「社員専用です」と返ってくる（合言葉を知らない人には答えない）
3. 合言葉を送る → 「登録しました」と返ってくる
4. 「売れ筋の在庫が少ないです」などと送る → 数秒でAIが答える
5. スプレッドシートの「応答ログ」に記録が残っていることを確認する

## 手順9（任意）｜緊急時に本間さんのLINEにも知らせる

1. 本間さん自身が、手順8の2〜3で合言葉を送って登録する
2. スプレッドシートの「社員名簿」に本間さんの行が増えるので、その **LINEユーザーID**（Uで始まる英数字）をコピー
3. スクリプト プロパティ ⑦ `OWNER_LINE_USER_ID` に登録する
   - 「緊急」のものだけ、本間さんのLINEにも届くようになります
   - この通知はLINEの無料通数を使います（緊急だけなので、通常はわずか）

## 運用中によくある作業

| やりたいこと | やり方 |
|---|---|
| **AIの答え方を変えたい** | 応答ルールのGoogleドキュメントを直すだけ。10分以内に反映 |
| **辞めた社員を使えなくしたい** | 「社員名簿」シートからその人の行を消す |
| **合言葉を変えたい** | スクリプト プロパティ ⑥ を書き換える（登録済みの社員はそのまま使える） |
| **コード.gs を直した** | **デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新バージョン」→ デプロイ**（こうするとURLが変わらない） |
| **AIが動いていない気がする** | 本間さん宛てに「【右腕AI】エラーが起きました」のメールが届いていないか確認。Apps Script の「実行数」でも確認できる |

## 知っておいてほしい注意点

- **ウェブアプリのURLは人に教えない。** この方式（Apps Script）は、LINE以外からの送信を見分ける仕組みを入れられません。代わりに「合言葉で登録した社員にしか答えない」ことで守っています
- **AIのモデル**：Anthropic社の最新の上位モデル（claude-opus-5-5）を、速さ重視の設定で使っています。まれにAIが回答を見送った場合、別のモデルで自動的にやり直す設定も入れてあります
- **会話の記憶**：社員ごとに直近6往復を、6時間だけ覚えています。それより前の話は覚えていません
- **記録の扱い**：「応答ログ」には社員の質問がそのまま残ります。スプレッドシートの共有範囲は本間さんだけにしてください
