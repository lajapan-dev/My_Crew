# 蓄積フォルダ｜右腕AIの週次振り返り

## 何を溜めるか
右腕AIが社員とやり取りした内容の **週ごとの振り返りメモ** だけを溜めます。
やり取りの全文は、Googleスプレッドシート「右腕AI_応答ログ」が正本です。ここに全文は写しません。

1枚に書くのは、これだけで十分です。
- 今週の質問件数／本間さんに回った件数
- よく出た質問（→ `../03_よくある質問.md` に手本として足す候補）
- おかしかった答えと、直したルール
- 「社員に任せてよい範囲」で、新しく決めたこと

## 命名ルール
`YYYY-MM-DD_週次振り返り.md`（日付はその週の月曜日）

## 更新頻度
週1回。週次レビュー（`09_テンプレート/週次レビュー.md`）のついでに。
本間さんは「今週の応答ログを見て振り返りを作って」とClaude Codeに頼むだけでよい（スプレッドシートの中身を貼り付けるか、ダウンロードして渡す）。

## 機密の扱い
- 社員の名前は、イニシャルか役割（例：「出品担当」）で書く
- 顧客名・契約金額・個人的な相談の中身は書かない
