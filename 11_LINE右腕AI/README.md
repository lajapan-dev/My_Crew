# 11_LINE右腕AI｜社員の質問に、本間さんの代わりに答える仕組み

最終更新：2026-10-27

## この部屋は何か

社員からLINEで届く仕事の質問に、**AIが本間さんの判断基準に沿って、本間さんの代わりに即答する仕組み** の置き場所です。
「自分が止まると全部止まる」「夜に問い合わせが来ると休めない」という課題に、直接効かせるための部屋です。

**本間さんの決定（2026-10-27）**
- 対象：**社員からの質問**
- 任せる範囲：**ほぼ全部AIに任せる**（お金・クレーム・契約などの一部だけ本人に回す）
- 窓口：個人LINEではなく、**社員専用のLINE公式アカウント** を新しく作る（理由は `01_導入の道のり.md`）

## この部屋の中身

| ファイル・フォルダ | 何が書いてあるか | 誰が使うか |
|---|---|---|
| `01_導入の道のり.md` | なぜ公式アカウントか／費用／4段階の進め方／社員へのお知らせ文例／将来の候補 | 本間さん |
| `02_応答ルール.md` | 右腕AIが毎回読む「答え方の憲法」。判断基準・DON'Tリスト・本人に回す基準 | 右腕AI（Googleドキュメントに貼って使う） |
| `03_よくある質問.md` | 「社員に任せてよい範囲」の記入欄と、答えの手本 | 本間さんが書き込み、右腕AIが読む |
| `応答ログ/` | 毎週の振り返りメモを溜める場所 | 本間さん・Claude Code |
| `仕組み/設置手順.md` | 画面のどこを押すかまで書いた設置手順 | 設置を担当する人 |
| `仕組み/コード.gs` | LINE・Googleドキュメント・Claudeをつなぐ小さなプログラム | 設置を担当する人（さわらなくてよい） |

## 正本（いちばん正しい版）はどこか

- **応答ルール・よくある質問の正本は、Googleドキュメント側**（右腕AIが実際に読むのはそちら）
- このフォルダの `02` `03` は、Claude Code（経営参謀）が同じ前提で考えるための **写し**
- Googleドキュメントを直したら、こちらにも同じ修正を写す（Claude Codeに「写して」と頼んでよい）
- やり取りの記録の正本は、Googleスプレッドシート「右腕AI_応答ログ」

## AI（Claude Code）への指示

- 本間さんが「右腕AIの答えが違った」と雑メモに書いたら、`02_応答ルール.md` または `03_よくある質問.md` の **直し方を提案** する（直接の書き換えは本人の確認後）
- 週次レビューのときに、`応答ログ/` の最新メモを見て「本人に回った件数」「よく出る質問」を確認し、**手本への追加** を1つ提案する
- `03_よくある質問.md` の「A. 社員に任せてよい範囲」に [未記入] が残っていれば、**1つずつ埋めるよう** 提案する（埋まるほど本間さんに回る件数が減る）
