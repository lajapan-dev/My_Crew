# Shopee売上データ｜要約の置き場

**何を溜めるか**
国別・SKU別の**売上と粗利の月次要約**。日々の数字は入れません。

**原本はどこにあるか**
Googleスプレッドシート等（[要確認]。分かり次第ここに書いてください）

**ファイル名**
`YYYY-MM_売上サマリー.md`

**1ファイルに書く項目（目安）**
- 国別の売上・粗利
- 売れ筋SKU上位と、その粗利率
- 前月比で目立った動き
- 気づいたこと・次にやること

**更新頻度**
月1回（月初に前月分）。

**AIへの指示**
- **これは最重要KPI（Shopee粗利）の実績そのもの**。月次レビューで必ず参照する
- 3か月分溜まったら、傾向の変化を指摘する
