# Shopee売上データ｜要約の置き場

**何を溜めるか**
国別・SKU別の**売上と粗利の月次要約**。日々の数字は入れません。

**原本はどこにあるか（正本）**
- **売上の正本**：Shopee Seller Centre の**メインアカウント**（ここから取得する）
- **入金の正本**：**Payoneer**（実際に入金された額）
- **この2つを突き合わせて初めて、実際の粗利が確定する**

**⚠️ 取得について**
ShopeeとPayoneerには、AIが直接つながっていません（今つながっているのは
Gmail・Googleドライブ・カレンダー等のみ）。
当面は、**本間様がダウンロードしたファイルを渡していただければ、AIが集計・突合・要約します。**

**ファイル名**
`YYYY-MM_売上サマリー.md`

**1ファイルに書く項目（目安）**
- 国別の売上・粗利（Shopee側の数字）
- **Payoneerの入金額と、その差額**（手数料・為替でどれだけ目減りしたか）
- 売れ筋SKU上位と、その粗利率
- 前月比で目立った動き
- 気づいたこと・次にやること

**更新頻度**
月1回（月初に前月分）。

**AIへの指示**
- **これは最重要KPI（Shopee粗利）の実績そのもの**。月次レビューで必ず参照する
- 3か月分溜まったら、傾向の変化を指摘する
