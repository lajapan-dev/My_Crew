# 03_外部データ｜この部屋について

**何をしまう場所か**
他のシステム（スプレッドシート、Shopeeの管理画面、Gmail など）にある数字や情報の、
**要約だけ**をしまう引き出しです。

**大事な考え方：原本はここに移さない**
- 数字の**正本（いちばん正しい版）は、元のツールに置いたまま**にします
- ここに置くのは「今月はこうだった」という**要約**と、「原本はどこにあるか」という案内だけ
- 理由：原本を二重に持つと、どちらが正しいか分からなくなるからです

**部屋の分け方（データの種類ごと）**
| フォルダ | 何の要約か | どちらの事業か |
|---|---|---|
| `01_AI最新情報/` | AIの最新ニュース・リサーチのログ | 事業A（研修ネタ）＋両事業の実務 |
| `02_Shopee売上データ/` | 国別・SKU別の売上と粗利の要約 | 事業B |
| `03_為替レート/` | 為替の水準と、粗利への影響メモ | 事業B |
| `04_Shopee手数料_ポリシー/` | 手数料率・規約変更の要点 | 事業B |
| `05_研修アンケート/` | 研修参加者アンケートの要約 | 事業A |
| `06_AI研修_売上と問い合わせ/` | AI研修の月の売上と新規問い合わせ件数（今四半期の目標の実績） | 事業A |

※ 1つのデータが1つの事業にほぼ対応しているため、事業別の小分けはしていません。
　 両事業にまたがるデータが増えてきたら、そのとき `A_` `B_` の小分けを足します。

**どの引き出しのREADMEにも書いてあること**
何を溜めるか／原本はどこにあるか（正本）／ファイル名の付け方／更新頻度／AIへの指示

**AIへの指示**
- ここは**頼まれたときだけ**読む
- 数字を答えるときは、**いつ時点の要約か**を必ず添える
- 要約しかないので、**正確な最新値が必要な場面では「原本を確認してください」と伝える**
