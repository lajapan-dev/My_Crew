# 03_外部データ｜この部屋について

**何をしまう場所か**
他のシステム（スプレッドシート、Shopeeの管理画面、Gmail など）にある数字や情報の、
**要約だけ**をしまう引き出しです。

**大事な考え方：原本はここに移さない**
- 数字の**正本（いちばん正しい版）は、元のツールに置いたまま**にします
- ここに置くのは「今月はこうだった」という**要約**と、「原本はどこにあるか」という案内だけ
- 理由：原本を二重に持つと、どちらが正しいか分からなくなるからです

**部屋の分け方（データの種類ごと）**
| フォルダ | 何の要約か |
|---|---|
| `01_AI最新情報/` | AIの最新ニュース・リサーチのログ |
| `02_Shopee売上データ/` | 国別・SKU別の売上と粗利の要約 |
| `03_為替レート/` | 為替の水準と、粗利への影響メモ |
| `04_Shopee手数料_ポリシー/` | 手数料率・規約変更の要点 |
| `05_研修アンケート/` | 研修参加者アンケートの要約 |

**AIへの指示**
- ここは**頼まれたときだけ**読む
- 数字を答えるときは、**いつ時点の要約か**を必ず添える
- 要約しかないので、**正確な最新値が必要な場面では「原本を確認してください」と伝える**
