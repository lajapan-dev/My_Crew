# AI研修の売上と新規問い合わせ｜月次の要約置き場（事業A）

**なぜこの引き出しがあるか**
事業Aの今四半期の目標は **「月の売上100万円以上」「新規問い合わせ 月10件以上」** です。
ところが、この2つの数字を記録する場所がこれまでありませんでした。
数字が残らないと、AIは「目標にどれだけ近づいたか」を朝ブリーフや週次レビューで言えません。

**何を溜めるか**
- その月の **AI研修の売上合計**（商品ライン別：フロント／ミドル／バックエンド）
- その月の **新規問い合わせの件数**と、どこから来たか（紹介・登壇・Web など）
- 助成金を使える案件だったか
- 目標との差と、気づいたこと

**原本はどこにあるか（正本）**
- 売上：Stripe／Square／請求書の控え のどれが正本かは **[要確認]**
- 問い合わせ：Gmail／Chatwork／LINE／Facebook に分かれて届いている（どこを数えるかは **[要確認]**）
- ここに置くのは **月の合計と要約だけ**。明細・顧客名・金額の内訳は原本側に置いたままにする

**ファイル名**
`YYYY-MM_AI研修実績.md`（月に1ファイル）

**1ファイルの書き方（これだけでよい）**
```
# 2026-11 AI研修実績
- 売上合計：○○万円（目標100万円）
- 新規問い合わせ：○件（目標10件）／内訳：紹介○・登壇○・Web○
- 助成金対象の案件：○件
- 気づき：
```

**更新頻度**
月1回（月初に前月分）。問い合わせは、来るたびに `07_雑メモ/雑メモ.md` に1行書いておけば、月末にAIが数えます。

**⚠️ 注意**
顧客名・個人名・契約ごとの金額は書かない（「A社」等の記号で）。

**AIへの指示**
- 週次レビュー・月末の振り返りで、**目標（100万円／10件）との差**を必ず示す
- 問い合わせが目標に届かない月は、**既存顧客・既存の登壇からの紹介**など、DON'Tリストに触れない入口を提案する
