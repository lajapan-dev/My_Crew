# AI最新情報｜リサーチログ

**何を溜めるか**
AIの最新ニュース・新機能・他社事例のうち、**研修で使えるもの／実務に効くもの**だけ。
「読んだ」ではなく「**どう使えるか**」を1行添えるのがコツです。

**書き方（1件1行でよい）**
- 日付／何があったか／研修に使えるか／実務に使えるか

**ファイル名**
`YYYY-MM_AIリサーチ.md`（月ごとに1ファイル、追記していく形）

**更新頻度**
気づいたとき随時。まとめて週1回でもよい。

**AIへの指示**
研修ネタになりそうなものには **【コンテンツ資産化】** を付ける。

---

## 毎日の定例：AIツール導入検討レポート（本人指示 2026-11-23）

**何をするか**
毎朝、AIが新しいAIツール・新機能を調べ、「うちに入れるべきか」を仕分けて報告する。

**AIの手順**
1. **材料を集める**
   - ウェブ検索で、直近1〜2日のAIの新ツール・新機能を調べる（Claude／Gemini／ChatGPT／Genspark／Gammaなど、代表が使っている道具の更新を優先）
   - `07_雑メモ/雑メモ.md` に代表が貼った投稿・リンク・画面写真の内容があれば、それも対象にする
2. **仕分ける**（`01_会社の土台/04_判断基準.md` と `06_DONTリスト.md` に従う）
   - **導入する**／**試す**／**見送り** の3つに分ける
   - 報告は**最大3件**まで。該当なしの日は「今日は該当なし」と1行で終える（無理に埋めない）
   - すでに持っている道具と役割が重なるものは見送り
   - 宣伝目的と思われる情報、運営元が確かめられないツールは、その旨を書いて見送り
3. **記録する**
   - 当月の `YYYY-MM_AIリサーチ.md` に1件1行で追記（研修ネタには【コンテンツ資産化】）
   - 「導入する／試す」になったものだけ `08_todo/` に追加
4. **報告する**：チャットに短く（結論→理由→代表がやること）

**AIが勝手にやらないこと**
- 有料の契約・アカウント登録・支払い（代表が行う）
- ワークスペースの中で完結する取り入れ（手順やひな形の追加など）は、AIが行って報告する

**限界（知っておくこと）**
- **AIは代表のX（旧Twitter）のホーム画面を見られない**。ログインが必要な画面のため。
  Xで気になった投稿は、画面写真かリンクを雑メモかチャットに貼れば、翌朝のレポートで検討する
- 代わりに「必ず見てほしいXアカウント」を下に書いておけば、その人の発信を検索で追う（追える範囲に限りあり）
