# 研修アンケート｜要約の置き場

**何を溜めるか**
研修・セミナー参加者のアンケートのうち、**次に活かせる部分**の要約。
生の回答すべてではなく、「刺さった点」「分かりにくかった点」「次への改善」。

**ファイル名**
`YYYY-MM-DD_研修名_アンケート要約.md`

**更新頻度**
研修を実施した直後。

**⚠️ 注意**
参加者の氏名・所属・連絡先などの**個人情報は書かないでください**。

**AIへの指示**
