# 10_中間サマリー｜この部屋について

**何をしまう場所か**
`SUMMARY.md`（会社全体の1枚概要）と、個別のファイルとの**あいだ**にある、
**事業ごとのまとめ**を置く引き出しです。

**なぜ「中間」が必要か**
- 全体概要だけでは、事業の細かい話には答えられない
- かといって個別ファイルを全部読むと、情報が多すぎて判断がぼやける
- **だから、あいだに1段はさみます**

**読む順番の中での位置**
1. `CLAUDE.md`（運用ルール）
2. `SUMMARY.md`（会社の全体像）
3. **`10_中間サマリー/`（← ここ。必要なときだけ）**
4. 個別ファイル（本当に必要なものだけ）

**更新頻度**
週1回の振り返りのとき、または大きな動きがあったとき。

**AIへの指示**
週次レビューのときに、このファイルの更新案を出すこと。
