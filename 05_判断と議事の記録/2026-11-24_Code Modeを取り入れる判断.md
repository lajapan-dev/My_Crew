## 何を決めたか
- 本人の依頼（「Code Modeを学習して、取り入れて」）により、Code Modeを次の3つの形で取り入れる
  1. **知識として**：調査レポートとAIリサーチログに記録（`04_調査とレポート/2026-11-24_Claude CodeのCode Modeの検証.md`）

- **このワークスペースでCode Modeをオンにすることは、今はしない**

## なぜそう決めたか（★ここが最重要）
- Code Modeは **パソコンのターミナル（文字だけの黒い画面）でしか動かない実験機能**。本間さんがふだん使うクラウド版（ブラウザ・スマホ）では使えない
- このワークスペースは文章中心でファイル数も少なく、Code Modeの「大量の作業をまとめて片づける」強みが活きる場面がまだない
- 一方で「AIが一手ずつではなく段取りを組んで動く」という流れは、法人研修（最重要KPI）の題材として強い

## 見送った選択肢と、その理由
- **今すぐこのワークスペースでオンにする** → クラウド版では動かず、オンにする設定もこのワークスペースのファイルからは入れられない仕組み
- **AIパッケージの標準に入れる** → 実験機能で、提供元の都合で変わる・消える可能性がある。お客さまの大半はターミナルを使わない。AI案として「控え」に留めた【要本人判断】
