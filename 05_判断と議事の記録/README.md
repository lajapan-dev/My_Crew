# 05_判断と議事の記録｜この部屋について

**何をしまう場所か**
**決めたことと、その理由**をしまう引き出しです。この部屋がこのワークスペースで
いちばん効いてきます。

**なぜ大事か**
本間様の課題に「**感覚で仕入れて外したとき、後から振り返る材料がない**」があります。
これは「決めた理由」が残っていないから起きます。
**理由さえ残っていれば、外したときに何を読み違えたかが分かり、次に活きます。**

**ここに入るもの**
- 仕入・価格・取引条件の判断とその理由
- 案件を受ける／断る判断
- 方針変更（今期やる・やらないの変更）
- 打ち合わせの議事メモ

**ファイル名**
`YYYY-MM-DD_何を決めたか.md`　例：`2026-10-15_A社案件を受ける判断.md`

**1枚に書くこと**
- 何を決めたか
- **なぜそう決めたか（これが最重要）**
- そのとき分かっていなかったこと
- 結果（後日わかったら追記する）

**テンプレート**：`09_テンプレート/判断記録.md` をコピーして使えます

**更新頻度**
判断したとき。1〜2行でもよいので、**その場で残すこと**。

**AIへの指示**
- 重要な判断をした会話の後は、**この部屋への記録を提案する**
- 過去の似た判断がないか、必要に応じて参照する
