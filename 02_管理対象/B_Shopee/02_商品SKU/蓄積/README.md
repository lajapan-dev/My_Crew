# 蓄積フォルダ｜商品（SKU）の記録

**この箱に何を入れるか**
SKUごとの粗利メモ、仕入判断の理由と結果の振り返り、価格見直しの記録、カテゴリ別のトレンド観察。**「なぜ仕入れたか」「結果どうだったか」をセットで残すこと**が、感覚判断から数字判断へ移るための材料になります。

**ファイル名の付け方**
`YYYY-MM-DD_SKU名orカテゴリ_内容.md`　粗利一覧は `粗利一覧.md`

**更新の頻度**
仕入判断をしたとき／価格を見直したとき／月次の粗利確認のとき。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
