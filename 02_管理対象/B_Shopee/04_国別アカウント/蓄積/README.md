# 蓄積フォルダ｜国別アカウントの記録

**この箱に何を入れるか**
評価スコアの推移、違反警告とその対応、国別の売上傾向、アカウント運用上の気づき。

**ファイル名の付け方**
`YYYY-MM-DD_国コード_内容.md`　例：`2026-10-05_SG_評価低下の対応.md`

**更新の頻度**
警告や評価の変化があったとき／月次の確認のとき。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
