# 蓄積フォルダ｜顧客問い合わせの記録

**この箱に何を入れるか**
来た問い合わせの内容と、返した答え。**完璧に書かなくてよい。1行でよい。** これがテンプレ5パターンの材料になります。完成したテンプレは `テンプレ集.md` にまとめます。

**ファイル名の付け方**
`YYYY-MM-DD_問い合わせ内容の要約.md`　テンプレは `テンプレ集.md`

**更新の頻度**
問い合わせが来たとき。まとめて週1回でもよい。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
