# 蓄積フォルダ｜仕入先との記録

**この箱に何を入れるか**
交渉の経緯と結果、提示された条件、値引き交渉の材料になる実績数字、取引上の注意点。

**ファイル名の付け方**
`YYYY-MM-DD_仕入先記号_内容.md`　例：`2026-10-01_S社_条件交渉.md`

**更新の頻度**
交渉・やりとりがあったとき。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
