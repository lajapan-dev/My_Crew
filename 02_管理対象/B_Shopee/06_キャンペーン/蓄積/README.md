# 蓄積フォルダ｜キャンペーンの記録

**この箱に何を入れるか**
キャンペーンごとの準備内容、実施後の結果（売上・粗利）、次回への反省点。**結果を残すことで、次回の判断材料になります。**

**ファイル名の付け方**
`YYYY-MM-DD_キャンペーン名_内容.md`　例：`2026-11-11_11.11_結果.md`

**更新の頻度**
準備開始時と、終了直後。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
