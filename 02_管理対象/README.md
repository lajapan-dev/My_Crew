# 02_管理対象｜この部屋について

**何をしまう場所か**
案件・商品・仕入先など、**継続して面倒を見ている対象**をしまう引き出しです。
一度きりの調べものは `04_調査とレポート/` へ、日々の殴り書きは `07_雑メモ/` へ。

**なぜこの形なのか**
どの対象も、必ず **3点セット** で持ちます。

| | 名前 | 役割 | たとえるなら |
|---|---|---|---|
| ① | `概要シート` | 1枚で現状がわかる要約 | 表紙・カルテの1ページ目 |
| ② | `蓄積/` | 履歴・実データを時系列で溜める場所 | カルテの束が入った箱 |
| ③ | `_index.md` | 複数件あるときの一覧表 | 目次 |

**なぜ①と②を分けるのか**
概要シートだけ作って溜める場所がないと、中身が増えない「空の台帳」になります。
逆に溜めるだけで要約がないと、AIも人も全部読む羽目になります。両方いります。

**部屋の中の分け方**
- `A_AI研修/` … 事業A（AI研修）の管理対象
- `B_Shopee/` … 事業B（Shopeeコンサル）と自社ECの管理対象

**書き方のルール**
- クライアント名は「A社」等の記号で書く。実名・契約金額は、このワークスペースに直接書かない
- 概要シートは**1枚で読める分量に留める**。長くなったら中身は`蓄積/`へ移す
