# 蓄積フォルダ｜研修コンテンツ・教材

**この箱に何を入れるか**
教材の一覧、改訂の記録、「この回でここが刺さった／滑った」という手応えメモ。**資料そのもの（重いファイル）は元の場所に置いたまま、ここには要約と置き場所を書きます。**

**ファイル名の付け方**
`YYYY-MM-DD_教材名_メモ.md`　一覧表は `教材一覧.md`

**更新の頻度**
教材を作った・直したとき。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
