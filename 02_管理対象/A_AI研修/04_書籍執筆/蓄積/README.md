# 蓄積フォルダ｜書籍執筆

**この箱に何を入れるか**
目次案、章ごとの下書きメモ、使えそうな事例のネタ帳、編集者とのやりとりの要点。

**ファイル名の付け方**
`YYYY-MM-DD_内容.md`　ネタ帳は `ネタ帳.md`（1ファイルに追記していく形でよい）

**更新の頻度**
思いついたとき随時。締切が動いたら必ず。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
