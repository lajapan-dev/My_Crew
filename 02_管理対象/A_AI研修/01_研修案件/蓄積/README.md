# 蓄積フォルダ｜AI研修案件の記録

**この箱に何を入れるか**
打ち合わせメモ、提案書の控え、実施後の振り返り、参加者からの反応など、**案件ごとの経過**を時系列で入れます。

**ファイル名の付け方**
`YYYY-MM-DD_顧客記号_内容.md`　例：`2026-09-20_A社_初回打合せ.md`

**更新の頻度**
動きがあったとき。打ち合わせをしたら、その日のうちに1枚。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- 実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
