# 雑メモ｜とりあえずここに書く

**このファイルの役目**
きれいに書けなくていい。置き場所を悩まなくていい。
**思いついたこと、聞いた話、引っかかったことを、そのまま放り込む場所**です。

整理するのはAIの仕事です。あなたは書くだけでいい。

---

## 書き方のルール（ゆるくてよい）

- **完璧に書かない。1行でよい。** 単語だけでもよい
- 書式はバラバラでよい。話し言葉でよい
- 日付だけは、できれば入れる（あとで整理するときの手がかりになるため）
- 書けるときだけ、次の2つを添えると整理が早くなる（**書かなくてもよい**）
  - **誰の話か**：`誰：A社` `誰：社員` `誰：自分` など
  - **何に関係するか**：`件：11.11` `件：研修①` `件：S社` など
- 整理してほしいものには `#要整理` と書いておく
- **AIにやってほしいことがあれば、その場で書く**（下の一覧を参照）

**AIへの依頼の書き方（コピーして使う）**
- `#サマリー化して`
- `#todo化して`
- `#顧客別に整理して`
- `#次アクション出して`
- `#判断記録に残して`
- `#仕組み化案ちょうだい`

```
- 新しい問い合わせ1件（紹介経由）。誰：C社 件：AI研修 #todo化して
```

※ この見本は消さずに残しておいてください。書き方を忘れたときの手本になります。

## AIへの指示

- このファイルは**週1回まとめて読む**。毎回は読まなくてよい
- 読んだら、次を提案すること
  1. todoにすべきもの → `08_todo/` へ振り分け案を出す
  2. 案件・顧客に関するもの → `02_管理対象/` の該当する蓄積フォルダへの振り分け案を出す
  3. 判断に関するもの → `05_判断と議事の記録/` への記録を促す
  4. 繰り返し出てくる話題 → **【仕組み化候補】** として指摘する
- 処理し終えたメモは、`過去ログ/YYYY-MM.md` に移す提案をすること
- AI研修の **新規問い合わせ** らしきメモは、月末に件数を数えて `03_外部データ/06_AI研修_売上と問い合わせ/` に反映する
- 実名・電話番号・メールアドレスが書かれていたら、整理するときに **「A社」等の記号に置き換える** ことを提案する
- **書いた本人を責めない。書式が雑でも、そのまま受け止めて整理する**
