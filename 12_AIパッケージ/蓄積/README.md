# 蓄積フォルダ｜AIパッケージ

**この箱に何を入れるか**
パッケージの中身を変えた記録、お客さまに導入したときの手応えメモ、「この機能は刺さった／使われなかった」という振り返り、提供元（Anthropic）の仕様変更のメモ。

**ファイル名の付け方**
`YYYY-MM-DD_テーマ.md`
（例：`2026-12-01_A社導入_Whiteboardsの手応え.md`、`2027-01-15_Meetingsの提供条件変更.md`）

**更新の頻度**
パッケージの中身を変えたとき・お客さまに導入したとき。

**入れ方のコツ**
- 迷ったら、とりあえず入れる。整理はAIに頼めます
- 1ファイル1件。1つのファイルに何件も詰め込まない
- お客さまの実名・契約金額・個人情報は書かない（「A社」等の記号で書く）

**AIへの指示**
このフォルダの中身は、頼まれたときだけ読むこと。
普段は上の階層にある「概要シート」だけを見れば足ります。
お試し版の機能について、提供条件の変更を見つけたら、ここに1件メモを残し、概要シートの表を直す案を出すこと。
