# 12_AIパッケージ｜お客さまに売る「Claude Codeパッケージ」の部屋

最終更新：2026-11-12

## この部屋は何か
法人のお客さまに **「Claude Codeを経営参謀にする仕組み一式」** を作って渡す商品（AIパッケージ）の、中身と見本をしまう部屋です。
事業A（AI研修）の商品です。

## 中に入っているもの

| 名前 | 何か | いつ見るか |
|---|---|---|
| `概要シート.md` | **パッケージの中身の正本**。何が入っていて、お客さまに何の条件が必要か | まずこれだけ見ればよい |
| `AI組織ダッシュボード/` | AIの社員が働く様子を見せる画面（v1.0 納品版）。営業で見せる見本・お客さま版の元 | 画面を見せる・作り替えるとき |
| `蓄積/` | 中身を変えた記録、お客さまへの導入の手応え、提供元の仕様変更メモ | 振り返るとき |

## 中身を足すときのルール
- **新しい道具や見本を採用したら、まず `概要シート.md` の表に1行足す**。大きいもの（画面など）は、この部屋の中にフォルダを作って入れる
- 採用の判断は `05_判断と議事の記録/` に残す
- **価格・どこに入れるかは本間さんが決める領域**。AIは案を出すところまで

## AI（Claude Code）への指示
- AIパッケージの相談が来たら、`概要シート.md` だけを読む。他は必要になったときだけ
- お客さま版を作るときは、この部屋の見本を **コピーして** 作り替える（見本は残す）
- お客さまの実名・契約金額・個人情報は、この部屋に書かない（「A社」等の記号で書く）
